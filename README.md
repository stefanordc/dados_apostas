# Backtest Apostas

Web app com:
- React + Vite + TypeScript
- FastAPI
- PostgreSQL/Supabase

## Instalação / atualização
1. Coloque `download.zip` na raiz do projeto.
2. Execute:
   `powershell -ExecutionPolicy Bypass -File ".\atualizar_projeto.ps1"`
3. Depois:
   `powershell -ExecutionPolicy Bypass -File ".\iniciar.ps1"`
